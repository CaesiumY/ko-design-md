# 프리뷰 산문 감사 8차 — 소형 슬러그 3개 묶음 (11st · yeogi · teamsparta)

line-design-system(#242, squash `38983d1`)이 착지하면서 미감사 슬러그가 10개로 줄었다.
지금까지는 슬러그 하나에 PR 하나였으나 **여러 슬러그를 한 PR 로 묶어 달라는 요청**에
따라 이번부터 묶음으로 진행한다. **11st(27) + yeogi(7) + teamsparta(16)** 을 첫 묶음으로
잡았다.

**묶음 축은 크기다.** 대안(테마 분기가 큰 class101 20 · kyobobook 22 를 묶기)은 위험을 한
PR 에 몰아넣는 선택이다 — 분기가 많다는 건 다크 전용 서술이 많다는 뜻이고, **다크 전용
문장은 md 만 봐서 판정할 수 없다**(md 는 라이트 카노니컬 값만 싣는 경우가 많다).
소형 셋은 서로 독립적이라 파일이 겹치지 않고 커밋을 슬러그별로 나눌 수 있다.

## 일반 배너가 못 덮는 것

모든 프리뷰가 상단 고지 배너를 갖지만 열거 항목은 이것뿐이다:

> 표시된 **상품·가격·평점·거래·채용** 정보는 레이아웃 시연용 더미 데이터입니다.

그런데 세 슬러그가 그 밖의 허구 주장을 렌더하고 있었다:

- **11st** — `11STREET 단독 혜택` · `오늘 마감` · `앱 첫 구매 5천원 쿠폰` ·
  `11번가 멤버십 5% 추가` · `내일도착 · 새벽배송 가능`(판촉 카드) / 배송 소요일
  `영업일 기준 1~3일` · `새벽 7시 이전` · 취소 가능 시점 · `쿠폰존` 발급(FAQ 아코디언).
  **혜택 · 마감 기한 · 쿠폰 · 멤버십 · 배송/취소 정책**은 다섯 항목에 없다.
- **yeogi** — 멤버십 티어 혜택 `적립 · 전용가` · `우선 예약 · 추가 적립` ·
  `파트너 · 비즈 전용 혜택`.
- **teamsparta** — `누적 학습 시간 128h` · `과제 제출률 94% · **상위 12%**` ·
  마감 `오늘까지`/`3일 남음` · 라이브 세션 `오늘 19:30 · 현직 PM 코치와 함께`.

**`상위 12%` 는 백분위 순위 주장이라 PR #210 이 놓쳤던 범주 그대로다** — "허구 데이터
라벨은 수치가 아니라 주장까지; 배지·인증·순위·송장번호를 놓쳐 9곳 중 6곳 누락".

슬러그별 `catalog-dummy` 캡션은 **6개 슬러그에만** 있었다(krds 7 · gmarket 3 · toss 2 ·
wanted 2 · kyobobook 1 · teamsparta 1). 11st · yeogi 는 0건이었고, teamsparta 는 있었지만
**§02 안에 있어 §01 에 닿지 않았다.**

**문구를 새로 발명하지 않았다** — teamsparta 의 기존 형식(무엇이 더미인지 열거 +
"실제 …가 아닙니다")을 복사하고 열거 항목만 각 렌더에 맞게 바꿨다.

## 정정 문구가 또 틀렸다 — 네 번째, 이번엔 방향이 반대

yeogi 초안 캡션은 **"티어 이름과 혜택 설명은 … 더미"** 였다. `엘리트 플러스` 를 한글로
grep 해 0건이 나오자 발명된 티어명으로 판정했는데, **md 는 그것을 영문 토큰명으로
싣고 있었다:**

- md:196 — `Support/ 31종 — Benefit · Elite · **ElitePlus** · Favorite · Holiday …`
- md:198 — "**엘리트 티어(Elite/ElitePlus)**를 컬러 토큰 이름으로 승격시켰다 [src:13]"

**방향이 반대라 더 나쁘다** — 앞선 세 번은 허구를 사실처럼 쓴 것을 고쳤는데, 이 캡션은
**md 가 뒷받침하는 것을 허구라고 선언**했다. 커밋 전 서브에이전트 리뷰가 잡았다.

**교훈: 한글 프리뷰 문구를 md 에서 찾을 때 영문 토큰명도 함께 찾아야 한다.**
이 카탈로그는 토큰을 영문으로, 산문을 한글로 쓴다.

## grep 이 세 방향으로 오도했다

이번 묶음에서 세 가지가 **전부** 나왔다:

| 방향 | 사례 |
| --- | --- |
| 거짓 음성 | `엘리트 플러스` 0건 → md 는 `ElitePlus`(위) |
| 거짓 양성 | `56`·`64` 가 md 에 3건씩 히트 → 전부 컬러 hex 조각(`#249356` · `#5483FD`). **계획서가 이걸 근거로 "GNB 56h 근거 있음" 이라 적었다가 뒤집혔다** |
| 첫 히트 편향 | `단독 사용` 첫 히트가 shadow-flat 주의사항(md:376)이라 오귀속을 의심했으나, 실제 근거는 md:531 "Highlight 버튼을 그룹으로 배치하지 않는다 — 단독 사용만 허용된다" |

셋 다 **절을 열어야만** 갈린다. 세 번째는 특히 위험했다 — 억지로 고쳤다면 md 의 Don't
규칙을 무근거 문구로 대체할 뻔했다.
