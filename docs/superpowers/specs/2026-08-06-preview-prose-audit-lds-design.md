# 프리뷰 산문 감사 7차 — line-design-system

toss(#236, squash `05bce48`)가 착지하면서 미감사 슬러그가 11개로 줄었다. 대상은 표면이
두 번째로 많고(63 판정 단위) **#233 이 넘긴 미해결 질문이 걸려 있는**
line-design-system 이다.

**차수 표기 주의** — 이 작업을 진행하는 동안 #238 이 `프리뷰 산문 감사 6차 —
seed-design (묶음 H-6)` 으로 먼저 착지했다. 초안은 이 문서를 "6차" 로 적었으나 **7차로
조정**했다. 같은 이유로 **seed-design 은 더 이상 미감사가 아니다** — #209 의 제외 사유
("리뉴얼 준비 중")가 #231 의 전면 재생성으로 사라졌고 #238 이 감사를 마쳤다.

## 대조 결과 — 6개 표면 정정

| 유형 | 수 | |
| --- | --- | --- |
| md 가 **철회한** 주장이 살아 있음 | 2 | 푸터 고지 · CSS 주석 |
| md 가 갈라놓은 두 근거를 합침 | 1 | `타입 px·spacing은 …` |
| 프리뷰 자신의 CSS 와 어긋난 수치 | 1 | `명도 +6`(실제 +7) |
| 재현 범위를 실제보다 좁게 말함 | 1 | 다크 안내 |
| md 근거 0건인 통계 | 1 | `1억+ / 일본 MAU` |

**값을 말하는 자리는 거의 다 맞았고, "이 값이 어디서 왔는가" 를 말하는 자리가 틀렸다.**

## 정정 0건인 자리가 압도적으로 많다

`card-eyebrow` 20 + `card-title-text` 20 + `note-line` 5 + `section-sub` 7 +
`switch-desc` 3 + `check-desc` 2 가 **전부 md 와 일치**한다. 지금까지 감사한 슬러그 중
가장 잘 출처된 프리뷰다.

정밀도가 눈에 띈다 — `black-40` 이 md 의 "number page-indicator 배경",
`white-10` 이 "number-indicator 보더", `black-5` 가 "footer divider" 로 **용도까지** 맞고,
footer 노트(`items gray-500 · copyright gray-400 · 컨테이너 gray-150 · divider black-5 ·
375px 고정`)는 md:508 과 거의 축자적으로 같다. `enabled = outline` 도 md:529 의 정식
상태명이다(md:2 의 느슨한 "unselected" 가 아니라).

**`underline 2px` 는 리터럴 grep 0건이었지만 md:512 가 `underline M=2/S=1 … 기본
underline M(2)` 로 싣는다** — 표기만 보고 판정했다면 거짓 결함을 만들 자리였다.

## `.drawer` 이월 종결 — #233 의 질문에 답한다

#233 이 그리팅의 `.drawer*` 를 `.panel*` 로 바꾸면서 이렇게 남겼다:

> `line-design-system` 프리뷰도 `class="drawer"` 를 쓰지만 건드리지 않았다 — 미감사
> 슬러그이고 그쪽 md 에 `Drawer` 가 있는지 확인되지 않았다.

**확인했다. 리네임하지 않는다.** md 에 `### side-drawer` 절(md:523)이 있고, `## References`
가 공식 문서 `designsystem.line.me/LDSG/components/navigations/side-drawer-en` 를 두 번
인용하며(md:33 · md:637), 컬러 토큰 주석도 `side-drawer 메뉴 텍스트`(md:93)를 싣는다.

**그리팅과 정반대다** — 거기서는 md 전문에 `Drawer` 가 0건이라 클래스명이 근거 없는
컴포넌트명을 주장했지만, 여기서는 md 가 그 이름으로 문서화한다. #233 의 "이름이 같다는
이유로 다른 슬러그를 함께 고치면 근거 없이 범위를 넓히는 것" 이라는 판단이 실측으로
확인됐다.

## 정정 문구가 또 틀렸다 — 이 계열에서 세 번째

`3색뿐` 을 걷어내며 쓴 문장이 **두 군데서 어긋났다:**

1. **`타입 px·spacing은 공개 값 표가 없어`** — md:604 는 둘을 **명시적으로 분리**한다.
   타입 px 는 "공식 페이지가 이미지로만 공개한 것을 측정·재구성했고 **이미지 출처 인용
   가능**", spacing 은 "공식 페이지에 **수치 자체가 없어** 인용 가능한 공개 소스가 없다".
   내 문장은 md 가 일부러 갈라놓은 것을 하나로 묶었다.
2. **`Claude Design 번들`** — `Claude Design` 과 `번들` 은 **md 전문에 0건**이다. 이 어구는
   원문에 있던 것인데, 문장을 다시 쓰면서 **의심 없이 재사용해 재확인**한 셈이 됐다.

**앞선 두 번과 원인이 또 다르다:**

| 회차 | 상황 | 놓친 것 |
| --- | --- | --- |
| toss 1 | `white selected segment` | md 는 맞게 읽었으나 **다크 CSS 를 안 봄** |
| toss 2 | `removable 은 렌더 0건` | md 는 맞게 읽었으나 **마크업을 grep 으로만 봄** |
| 이번 | `타입 px·spacing … Claude Design 번들` | **md 문장을 읽었으나 두 축을 합침** + **원문 어구를 검증 없이 재사용** |

**교훈: 정정 문구를 쓸 때 원문에서 살려 오는 어구도 새로 쓰는 것과 같은 기준으로
검증해야 한다.** "고치는 부분" 만 보면 그 옆에 붙어 오는 무출처 어구가 통과한다.

## 표면 목록이 여섯 번째로 작았다

계획서가 잡은 목록 **밖**에서 결함 3건(`identity-stats` · CSS 주석 · 다크 안내 범위)과
관찰 6건이 나왔다. 빠졌던 자리:

`identity-stats` 3항목 · `field-help` 4 · `btn-rowlabel` 5 · 인라인 11px muted 캡션 12 ·
**버튼 라벨 자체가 규격을 주장하는 3곳** · `hero-meta` 4 · `dark-banner` · HTML/CSS 주석.

특히 **`identity-stats` 를 목업으로 분류한 게 틀렸다** — `1억+ / 일본 MAU` 는 md 에 근거가
0건인 사용자 수 통계인데, 바로 옆 `EN·JP·TC·TH / 언어 팩` 이 md:122 로 뒷받침되므로
**대비상 더 사실처럼 읽힌다.**

계수가 여섯 번 연속 작았고 매번 원인이 다르다 — H-1 단위 오류 · H-2 krds 4→30 ·
H-3 36→93 · H-4 49→그 이상 · toss 25→28 · 이번 63→그 이상.

## 남긴 것 중 판단이 갈린 자리

- **`Claude Design` 1건**(`light.html:14`) — "시각 풍부함은 Claude Design 시안의 카드별 grid
  패턴을 흡수" 는 **프리뷰 레이아웃의 제작 유래**이지 LDSG 값의 출처 주장이 아니다.
  같은 문자열이 자리에 따라 성격이 갈리므로 일괄 치환하지 않았다.
- **`gray-800 은 발행값 #2A2A2A 와 다릅니다`** — md:68 은 "24개 중 22개가 ΔE ≤ 0.02,
  2개가 ≤ 0.05" 라 0.02 를 넘는 토큰이 **둘**인데 md 가 나머지 하나를 특정하지 않는다.
  두 사실(개수 / gray-800 이 발행값과 어긋남)을 **분리해서** 적었다.
- **다크 `role-link-dark`** — 서브에이전트 리뷰가 "선언만 되고 미사용인 죽은 변수" 로
  봤으나 **그렇지 않다.** 이 PR 진행 중 착지한 #239(`fix(drift)`)가 바로 이 변수의
  chroma 를 `0.18` → `0.197` 로 고쳤다. 드리프트 검사기가 보고 있는 살아 있는 선언이다.
  **에이전트 보고를 그대로 받지 않고 확인해서 다행인 자리다.**
