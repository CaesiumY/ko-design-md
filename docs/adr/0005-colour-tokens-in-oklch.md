# 색 토큰은 OKLCH 로 적고, 브랜드 hex 는 대조 기준으로 남긴다

브랜드는 대개 hex 로 발행하지만, 카탈로그의 1차 독자인 LLM 이 hex 코드보다 명도·채도·색상 성분을 더 안정적으로 다룬다고 판단해 색 토큰 값은 OKLCH 로 적는다. 손으로 변환한 값이 한쪽으로 치우친 오차를 42건 낸 뒤로, 브랜드 hex 는 지우지 않고 곁에 남겨 OKLCH 를 그에 맞추는 기준으로 삼는다 — hex 기록이 사라지면 재대조가 불가능하기 때문이다. 둘의 일치는 채도에 따라 민감도가 달라지는 성분별 허용오차 대신, 카탈로그 전수 분포로 보정한 Oklab 거리 하나로 판정한다.

## Considered Options

- hex 만 — 발행값을 그대로 보존하지만 1차 독자에게 불리하다고 판단했다. 이 판단을 측정한 적은 없다.
- OKLCH 만, hex 삭제 — 틀린 변환을 발행값과 대조해 고칠 방법이 사라진다.
