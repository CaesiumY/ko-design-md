# 항목은 한국어 DESIGN.md 하나만 싣는다

V0 PRD 는 항목마다 한국어 기본 파일과 의역한 영문 파일, 영문 라우트와 hreflang 을 계획했지만, 첫 스캐폴딩 설계가 한·영 라우팅을 후속 계획으로 미룬 뒤 영문 파일은 한 번도 만들어지지 않았다. 이제 이중 언어를 포기하고 항목마다 한국어 DESIGN.md 하나만 싣는다 — 카탈로그의 1차 독자인 LLM·코딩 에이전트는 한국어로 쓰인 DESIGN.md 를 번역 없이 그대로 읽고, 재대조·감사 메모·갱신일·어긋남 검사가 모두 파일 단위라 파일이 둘이면 유지 부담이 두 배가 되며 두 파일이 서로 어긋날 새 축이 생기고, 의역은 인용된 주장과 문장 단위로 대응하지 않아 인용이 그 출처의 내용과 일치해야 한다는 원칙을 영문판에서 지킬 수 없기 때문이다.

## Consequences

- 항목의 언어는 본문 언어를 뜻하고 늘 한국어다. "자료가 영어 위주면 영어로 표시한다"던 옛 기여 안내는 이 결정과 어긋나므로 고친다.
- 생산자 스킬에 남은 한·영 동시 생성 모드는 이 결정과 어긋나며, 별도 작업으로 걷어낸다.
