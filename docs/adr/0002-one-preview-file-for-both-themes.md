# 프리뷰는 라이트·다크를 한 파일에 싣는다

프리뷰는 테마마다 파일이 하나였고, 합치자는 제안은 처음에 "원시 바이트가 커진다"는 이유로 기각됐다. 그러나 프리뷰는 brotli 로 압축돼 서빙되므로 원시 바이트는 전송 비용이 아니었다. 실측해 보니 합치면 첫 로드가 약 2.6 KiB 늘지만, 테마를 바꿀 때마다 다른 테마 파일을 통째로 새로 받던 약 17.6 KiB 가 사라져서 한 파일로 합쳤다. 테마마다 다른 산문도 같은 파일에 싣되 화면·접근성 트리·찾기·복사 어디에도 보이지 않는 텍스트가 생기지 않는 방식으로 싣고, 검증과 리뷰의 대상은 실제로 서빙되는 문서 한 장이다.

## Considered Options

- 테마별 파일 유지 — 테마를 한 번만 바꿔도 합친 쪽보다 많이 받는다.
- 한 파일에 두 테마 산문을 모두 넣고 CSS 로 숨김 — 숨긴 텍스트가 찾기·복사·보조기기에 새어 나온다.
