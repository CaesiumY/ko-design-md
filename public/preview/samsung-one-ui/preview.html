버튼 — 단일 스타일 체계

회색 배경 = 중간 강조, 유채색 배경 = 높은 강조. radius 18px(무버전 발행 drawable 스펙 18dp).

한 화면에는 한 가지 버튼 스타일만 쓴다 — 강조는 배경색으로만 올린다.

바텀 바 — 아이콘 + 텍스트

최대 5버튼, 1버튼 금지. 초과분은 More options로.

버튼에는 아이콘과 텍스트를 함께 넣는다. 스크롤 다운 시 숨김 허용.

토스트 · 모션

토스트는 한 줄 안팎, 3줄 초과 금지. 가벼운 결과 안내 전용.

사진 1장을 저장했습니다사진 2장을 저장했습니다

등장·문구 교체·퇴장은 각 300ms, 새 문구는 이전 문구가 사라진 뒤 들어온다. 토스트 표시 시간은 발행되지 않아 반복 주기는 시연용이다.

액션 토스트

토스트에 동작 버튼을 붙여 내용과 관련된 동작을 바로 실행하게 한다. 다른 토스트처럼 정해진 시간이 지나면 사라진다.

복사했습니다앨범 보기 파일 1개를 받았습니다파일 열기

닫기·완료·확인처럼 팝업을 닫기만 하는 버튼은 넣지 않고, 동작 버튼은 하나만 둔다. 버튼을 누를 때까지 남는 스낵바와는 다르다. 2019 가이드 p.50

진행 표시 — 막대와 원

완료 시점을 알면 막대, 모르면 원. 진행 표시는 본문이나 방금 누른 버튼 자리에 두고, 화면을 덮는 진행 팝업은 피한다.

진행 상태는 레이아웃 시연용 더미 데이터다.
